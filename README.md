# Прогнозирование временных рядов (R)

## Описание задачи
Анализ и прогнозирование временного ряда международного авиапассажиропотока.

## Стек
R (fpp3, forecast, tsibble), статистический анализ.

## Что сделано
1. Проведена STL-декомпозиция (тренд, сезонность, остатки).
2. Применены тесты на стационарность (KPSS, Дики-Фуллера) и преобразование Бокса-Кокса.
3. Построено и сравнено 10 прогнозных моделей (Naive, ETS, SARIMA, Theta, гибридная STL+ARIMA).
4. Лучшая модель (STL+ARIMA) показала **MAPE = 24.8%** и RMSE = 46.5 тыс. на тестовой выборке.
5. Проанализирован структурный сдвиг (2000 год) и его влияние на точность прогноза.

## Файлы

*   `Проект` — полный отчет с графиками и выводами.
